Private Google Drive copies ☁️

Move a QA snapshot between your devices using Google's hidden app-data folder. Only the Google account you authorise can access the app's copy. This is an explicit backup/restore workflow, not continuous automatic sync; tasks are never silently merged or replaced.

Each copy contains household tasks, shopping and other Control Centre QA data. Copies are stored under the authorised Google account, not in this public GitHub repository. Google Drive API access must be enabled for the configured OAuth client.
